Course syllabus

Eight 2-hour sessions and a 1-hour app session across four weekends, from your first program to object-oriented programming, debugging and your own billing app.

  1. 01

    Introduction to Python

    Check exercises →

    Session 1, Weekend 1 (2 Hours)

    • What Python is, and where it's used in real work
    • Key features: easy to read, interpreted, dynamically typed, large standard library
    • A short history of Python, including Python 2 and Python 3
    • Installing Python and checking that it works
    • Setting up IDEs: VS Code, PyCharm and Jupyter
    • Writing and running your first Python program
    • Practice: print a short introduction about yourself
  2. 02

    Basic syntax and data types

    Check exercises →

    Session 2, Weekend 1 (2 Hours)

    • Python syntax: indentation, comments and statements
    • Variables and naming conventions
    • Data types: int, float, str, bool and None
    • Checking a type with type()
    • Type conversion with int(), float(), str() and bool()
    • Operators: arithmetic, comparison, logical and assignment
    • Practice: calculate a bill total and a simple percentage
  3. 03

    Input, output and working with text

    Check exercises →

    Session 3, Weekend 2 (2 Hours)

    • Showing output with print(), including sep and end
    • Reading user input with input()
    • Why input() returns text, and how to convert it to a number
    • Output formatting with f-strings
    • Output formatting with .format(), and a quick look at % formatting
    • Formatting decimal places and aligning text
    • Working with text: indexing, slicing, and methods such as strip(), split(), join() and replace()
    • Practice: build a small marks or salary calculator
  4. 04

    Control flow

    Check exercises →

    Session 4, Weekend 2 (2 Hours)

    • Conditional statements: if, elif and else
    • Nested conditions, and combining them with and, or and not
    • for loops and range()
    • while loops, and how to avoid endless loops
    • Loop control: break, continue and pass
    • Nested loops and common beginner mistakes
    • Practice: grade calculator, multiplication table and number patterns
  5. 05

    Data structures

    Check exercises →

    Session 5, Weekend 3 (2 Hours)

    • Lists: indexing, slicing, and methods such as append() and pop()
    • Tuples: immutability and unpacking
    • Dictionaries: keys and values, and methods such as keys() and items()
    • Sets: unique values and set operations
    • List comprehensions
    • Choosing the right data structure
    • Practice: remove duplicates and count how often items appear
  6. 06

    Functions and modules

    Check exercises →

    Session 6, Weekend 3 (2 Hours)

    • Defining functions with def and return
    • Parameters: positional, keyword and default
    • Flexible parameters with *args and **kwargs
    • Lambda functions
    • Scope: global and local variables
    • Using modules and packages with import
    • Installing packages with pip
    • Practice: write reusable functions and your own small module
  7. 07

    Object-oriented programming (OOP)

    Check exercises →

    Session 7, Weekend 4 (2 Hours)

    • Classes and objects, with __init__ and self
    • Attributes and methods
    • Inheritance and polymorphism
    • Magic methods such as __str__ and __len__
    • Decorators: @property and @staticmethod
    • Practice: build a BankAccount or Student class
  8. 08

    Files, error handling and debugging

    Check exercises →

    Session 8, Weekend 4 (2 Hours)

    • Reading and writing files with open() and with
    • Saving lists and dictionaries to a file with JSON
    • Common errors, and how to read a traceback
    • Handling exceptions with try, except and finally
    • Raising your own exceptions with raise
    • Recording what a program does with the logging module
    • Finding bugs step by step with pdb
    • Course review and next steps
    • Practice: find and fix the bugs in a broken program
  9. 09

    Build a desktop app with tkinter

    Session 9, Weekend 4 (1 Hour)

    • Windows, labels, entry boxes and buttons with tkinter
    • Showing lists and bills in tables with ttk.Treeview
    • Connecting buttons to your own Python code
    • Turning your SuperMart Billing project into a desktop app
    • Homework: finish the app's remaining features
