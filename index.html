Course syllabus

Ten modules that take you from Python basics to a project of your own.

  1. 01

    Getting started

    What Python is and where it's used, your first program, variables, data types, operators, input and output

  2. 02

    Decisions and loops

    if, elif and else, for and while loops, break and continue, logic practice problems

  3. 03

    Working with collections

    Strings, lists, tuples, dictionaries, sets and comprehensions

  4. 04

    Functions

    Defining and calling functions, arguments, return values, scope and lambda functions

  5. 05

    Files and errors

    Reading and writing files, CSV and JSON, handling errors with try and except, debugging

  6. 06

    Object-oriented programming

    Classes, objects, attributes, methods and inheritance

  7. 07

    Modules and tools

    The standard library, pip, virtual environments, Git and GitHub basics

  8. 08

    Python for data

    NumPy basics, data analysis with pandas, charts with Matplotlib, SQL basics from Python

  9. 09

    Automation and APIs

    Automating file tasks, calling web APIs, working with Excel files, building an automation script

  10. 10

    Final project and career prep

    Building and publishing a project on GitHub, Python interview questions, resume and LinkedIn tips
